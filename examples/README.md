# Example images

Index `gallery/` and search with `query/barack-obama-2012.jpg`. The two Barack Obama portraits are distinct photographs (2009 and 2012); Michelle Obama is a second subject. The group collage combines the two gallery portraits to exercise multiple-face detection. These are public-figure photographs, not private photos.
