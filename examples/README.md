# Celebrity demo photos

The gallery has **52 distinct TV/movie celebrity photos** (including 12 selected group shots); the two query photos are separate source images. Index `gallery/` and search with either query. Every file is a Wikimedia Commons JPEG thumbnail resized by Commons to 800 px wide; no photo was synthesized or privately sourced. Some original Commons files are already cropped or retouched, as their titles indicate. Image licenses differ: preserve each photographer credit, linked source and license when redistributing. Similarity scores are not proof of identity.
